# ADR-0002: Источники как плагины (порт SourceConnector + конфиг)

- **Дата:** 2026-10-12
- **Статус:** accepted
- **Связанные документы:** PLAN.md §3.1, AGENTS.md, docs/SOURCES.md

## Контекст
Источники вакансий нестабильны: hh закрыл анонимный API (04.2026), часть площадок за CF, у каждой свои лимиты и форматы. Требование владельца: новые источники подключаются **без пересборки проекта**.

## Варианты
1. **Порт + плагины**: `SourceConnector` (Protocol) + реестр (builtins + entry points) + `connectors.yaml` (enabled/params/type).
2. Хардкод коннекторов в ядре — просто, но каждая правка = изменение ядра и релиз.
3. Универсальный «скребковый движок» с DSL — мощно, но хрупко и противоречит C2 (белые источники).

## Решение
Вариант 1. Универсальные типы (например `type: rss`) позволяют подключать источник **только YAML-ом**; специализированные — отдельным модулем с тестом на respx-моке.

## Последствия
- Плюс: подключение hh/SuperJob/Trudvsem/новых RSS не трогало ядро; выключение источника — одна строка.
- Минус: у плагинов дублируется маппинг полей — компенсируется общими утилитами (strip_html, Salary, Employer).
- Откат: при стабилизации числа источников можно «зацементировать» hot-path, сохранив порт.
