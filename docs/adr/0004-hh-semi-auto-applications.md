# ADR-0004: Отклики на hh.ru — полуавтоматика с подтверждением вместо автоотправки

- **Дата:** 2026-10-12
- **Статус:** accepted
- **Связанные документы:** docs/requirements.yaml FR-005, FR-003; docs/DISCOVERY.md §2.1, §7.5→§7 (F3); docs/PRODUCT.md C2, C4; docs/SOURCES.md §B, §F; PLAN.md M4 (v0.4.0)

## Контекст
Отправка отклика — ручная часть гибрида (C4). hh.ru официально борется с авто-откликами, а скрапинг/браузерная автоматизация против ToS и грозит баном аккаунта (SOURCES.md §F). Контрпример из ресёрча: НейроКарьера шлёт 60 автооткликов/день с конверсией ~4.6% (13 приглашений / 280 откликов за 14 дней; DISCOVERY §2.1) — риск бана для владельца неприемлем. Для hh доступен официальный OAuth user-флоу (нужны credentials dev.hh.ru, SOURCES.md §B), что даёт легальный канал отправки без обхода антибота.

## Варианты
1. **Полностью ручной отклик** — сервис только готовит текст, всё остальное делает владелец на сайте. Плюсы: нулевой риск, минимальный код (нет интеграции отправки). Минусы: теряется фиксация факта отправки, лишние ручные шаги, F3 остаётся без замкнутого контура.
2. **Полуавтоматика с подтверждением** — сервис по OAuth готовит отклик (текст + выбор резюме), владелец подтверждает, сервис отправляет с учётом лимитов/пауз. Плюсы: легально (официальный API), риск бана контролируется подтверждением и лимитами, факт отклика фиксируется в воронке. Минусы: нужен OAuth-коннектор и обработка лимитов/ошибок.
3. **Массовая автоотправка** — сервис рассылает отклики без подтверждения (как НейроКарьера). Плюсы: максимум объёма. Минусы: прямо противоречит C2/C4, риск бана аккаунта, ToS-риск; отвергнуто владельцем (DISCOVERY §7).

## Решение
Вариант 2 (полуавтоматика с подтверждением), реализующий FR-005. Критерий выбора: безопасность аккаунта и соответствие C2/C4 важнее объёма. Отклик уходит только после явного подтверждения; перед отправкой соблюдаются настраиваемые лимиты/паузы hh; при упоре в лимит отправка блокируется; результат (успех/ошибка/LIMIT) фиксируется в воронке. Режим «отправить всем без подтверждения» отсутствует.

## Последствия
- Плюс: легальный канал отклика, ноль обхода антибота, факт отклика попадает в воронку (метрики v0.5 получат данные).
- Минус: зависимость от одобрения приложения dev.hh.ru (SOURCES.md §B) и от соблюдения лимитов; нужны обработка OAuth-токена и состояний LIMIT/ошибок.
- Что теперь нельзя: автоотправку без подтверждения; браузерную автоматизацию hh (SOURCES.md §F); одновременную отправку по нескольким моделям (см. NFR-004).
- Откат: при недоступности OAuth фича деградирует до варианта 1 (FR-003 готовит текст, владелец отправляет вручную) — контур F3 сохраняется.
