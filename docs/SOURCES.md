# Реестр источников вакансий

> Живой документ. Правила: записи обновляются при каждой проверке; статус подтверждается датой
> эмпирической проверки (curl), а не памятью. Принцип: **максимально белые доступы**
> (официальные API / открытые данные / RSS), без скрапинга против ToS.

**Легенда:** ✅ подключён и работает · 🟡 код готов, выключен · 🔑 нужен бесплатный ключ (регистрация ~минуты) · ⏳ ключ/доступ с согласованием или платно · 🚫 закрыт/ToS-риск · ❓ не проверен

## E. Telegram-каналы (этап M4) — ⏳

Много нишевых вакансий публикуется только там. Доступ: Telethon + ваш аккаунт (user API). Отдельный коннектор, каналы — списком в конфиге. Кандидаты (из присланного обзора): t.me/normrabota и профильные агрегаторы IT/маркетинга/дизайна — сетку каналов уточним под вашу сферу.

## F. Закрытые/серые — 🚫 не используем как основу

| Источник | Ситуация на 2026-10-12 |
|---|---|
| LinkedIn | guest-эндпоинты закрыты/нестабильны, скрапинг → бан и ToS-риск |
| Indeed/Glassdoor/ZipRecruiter/Bayt | открытых API нет; JobSpy их скрапит (MIT), но против ToS площадок |
| hh.ru SSR-страница | `<template id="HH-Lux-InitialState">` отдаёт ≈59 полей curl'ом — ломается при любой верстке + риск бана |
| GeekJob | RSS/API не обнаружены (SPA), 404 на всех очевидных эндпоинтах — обзор пользователя обещает «простые GET», но не подтвердилось; отложен |
| GetMatch | официального API нет; предлагаемый обзором путь (перехват внутренних запросов фронтенда) — серая зона, отложен |
| Авито Работа | антибот-защита, нужны прокси и эмуляция человека — 🚫 |
| Работа.ру | только headless-браузер — 🚫 |
| hh.ru отклики через Selenium/Playwright | против ToS + риск бана аккаунта — 🚫 (отклики остаются ручными; см. M4 user-OAuth) |
| Careers Space / Facancy | закрытая/штучная экосистема — ручной просмотр, автоматизация нецелесообразна |
| Яндекс.Карьера и прочие корп-доски | частично стыкуются с категорией D — ❓ требуют проверки по списку целевых компаний |

## Как добавить новый источник (без пересборки ядра)

1. **RSS-источник** — только YAML: запись в `config/connectors.yaml` (`type: rss`, `feed_url`, опц. `item_parser`).
2. **JSON-API** — модуль в `src/job_hunter/connectors/` (реализует порт `SourceConnector`), фабрика в `connectors/__init__.py`, запись в `connectors.yaml`, тест на respx-моке.
3. **Внешний пакет** — entry point группы `job_hunter.connectors` в pyproject плагина.
